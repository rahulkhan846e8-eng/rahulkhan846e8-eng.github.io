# 👑 King Store Anime Streaming

A modern, high-performance anime streaming web platform built with clean HTML5, CSS3 (**Dark Blue `#091540` Theme** with royal gold accents), and modular ES6 JavaScript. Stream free in 1080p HD with zero subscriptions required.

---

## ✨ What's New & Key Features

- **👑 King Store Brand & Dark Blue Theme**:
  - Premium deep dark blue palette (`#091540`, `#050c24`, `#0e1d52`, `#132464`) with vibrant Royal Gold (`#ffbe0b`) & Electric Blue (`#3a86ff`) accents.
  - Crown logo badge and sleek glassmorphic navigation header.
  - 100% Free Streaming with all Premium and Mega Fan restrictions removed.

- **📂 Complete Categories Dropdown**:
  - Integrated mega-menu dropdown in the header with all 11 official anime categories:
    - ⚔️ **Action & Adventure**
    - 😂 **Comedy**
    - 💖 **Romance**
    - ☕ **Slice-of-Life**
    - 🌌 **Fantasy & Sci-Fi**
    - 🕵️ **Horror & Mystery**
    - 🌀 **Isekai**
    - 🤖 **Mecha**
    - 🪄 **Mahou Shoujo (Magical Girl)**
    - 🌿 **Iyashikei**
    - 💕 **Harem**

- **📚 Library & Instant Live Search**:
  - "Library" navigation replacing Simulcasts for fast browsing across all formats (TV series, Movies, OVAs).
  - Live search dropdown with debounce and instant genre tag filters.

- **🎬 King Store Custom Video Player**:
  - Full HD player with glowing gradient seekbar and timecode preview.
  - **"Skip Intro"** action button.
  - **"Next Episode"** quick trigger + 5-second autoplay countdown popup.
  - Subbed / Dubbed audio and subtitles switcher.
  - Playback speed control (`0.5x` to `2.0x`), Theater Mode, and Fullscreen.
  - Keyboard shortcuts (`Space`/`K` = Play/Pause, `←`/`→` = Seek 10s, `↑`/`↓` = Volume, `F` = Fullscreen, `M` = Mute, `S`/`I` = Skip Intro, `N` = Next Episode, `?` = Cheat Sheet).

- **⭐ Watchlist & Continue Watching**:
  - LocalStorage-powered watchlist (queue) and progress tracker across episodes.
  - Interactive community reviews with star ratings.

---

## 🚀 How to Run Locally

```powershell
py -m http.server 8000
```
Open **`http://localhost:8000`** in your browser.
